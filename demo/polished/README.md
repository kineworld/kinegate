# KineGate postproduction

Final deliverable: `../kinegate-demo-polished.mp4`. The earlier silent and narrated videos are preserved.

The browser pixels come from the existing actual `../capture.webm`, recorded by `scripts/record-demo.mjs`. The viewport is fitted onto a 16:9 stage, then approached with restrained, sine-eased camera moves. Product text and results were not re-created. FIXTURE, local simulation, recorded external REPLAY, missing execution evidence and the historical failed simulation retain their meaning. No successful trade, wallet connection, approval or broadcast is added.

Top context and mode labels remain fixed. Captions sit below the stage and never move with the camera. Short caption phrases match the synthetic narration text and are allocated within the actual measured cue speech durations. These are cue-aligned editorial timings, not an independently transcribed word alignment.

`project/DESIGN.md` defines the yellow/near-black palette. `project/index.html` is an editable HyperFrames/GSAP composition, with local GSAP and system-font declarations. The actual HyperFrames 15-second render is `../hyperframes-sample.mp4`; its render log is `qa/hyperframes-sample-render.log`. The final full-length export uses `render_stream.py` and FFmpeg's streaming zoom/pan implementation of `camera-plan.json`, avoiding thousands of intermediate frame files on a nearly full C drive. Both paths use the same editorial focus keyframes and easing; they are not claimed to be byte-identical exports. The final export's captions use short phrase groups; the HyperFrames preview uses full cue text.

The source recorder did not preserve exact mouse-down telemetry. `zoom-matches.json` identifies recorded action cue starts and camera ramp/hold timings; focus coordinates are editorial choices, not measured click positions. There is no fabricated pointer or mouse log.

## Audio

Natural synthetic narration is the Andrew neural voice generated by the separate narration workflow. Its source, disclosure, measured speech durations and light tempo adjustments are documented in `../narration-neural-timing.json`. The on-screen footer and introduction disclose synthetic narration.

“Evidence Before Action” is an original, AI-assisted ambient score synthesized locally by `synthesize_music.py`. It uses deterministic sine oscillators, diatonic chords, bass, a sparse motif and soft pitched percussion. No third-party samples, recordings, purchased generation service or random noise are incorporated. Factual attribution: **KineGate — original synthetic ambient score, AI-assisted composition**. See `music-provenance.json`; this provenance statement is not a claim of legal clearance for every conceivable musical similarity.

The narration is normalized toward −16 LUFS. Background music is normalized and sidechain-ducked with 80 ms attack and 700 ms release; the final measured music stem is −25.8 LUFS. The final AAC mix measured −16.4 LUFS and −1.6 dBFS true peak. Not independently auditioned; naturalness preference remains listener-dependent.

## Reproduce

Requirements: FFmpeg/FFprobe on PATH, Python with numpy, Node ≥22. Run `npm ci` in `project/` to install pinned GSAP, then copy `node_modules/gsap/dist/gsap.min.js` to `project/gsap.min.js` (the build script also performs this copy). The real `demo/capture.webm` and `demo/kinegate-narration-neural.wav` are required local media inputs. They are not reconstructed from invented frames. For direct HyperFrames rendering, the real capture and final `project/mix.wav` must be supplied as local inputs or separate release media; the full reproduction script regenerates the mix from the narration and original score.

```powershell
cd demo/polished
./reproduce.ps1 -Python <python-with-numpy>
```

The source repository intentionally excludes large audio/video inputs, generated GSAP bundles, node_modules, generated AGENTS/CLAUDE files and lengthy render logs. The final MP4, matching SRT and review sample can be distributed as release assets. Media hashes in the QA summary identify the particular local source inputs used here.

The script overwrites the **polished** export only. Use a copy if preserving a particular final version. It does not modify old recordings, application code, API data or fixtures. No credentials, chain transactions or paid services are required.

HyperFrames checks use the installed Edge browser on this host:

```powershell
$env:HYPERFRAMES_BROWSER_PATH='C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe'
npx --yes hyperframes@0.8.133 check project --json
```

`qa/final-ffprobe.json`, loudness logs, visual stills and `qa/final-qa.json` record the final checks. Git and publication are handled separately.
